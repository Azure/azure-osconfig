# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Before filing
a new issue, please search the [existing issues](https://github.com/microsoft/kompli/issues)
to avoid duplicates. If you find a related issue, add a 👍 reaction or a comment
with additional context instead of opening a new one.

When the existing issues do not cover your problem, open a new issue and choose the
type that best matches your request:

- **Bug report** — include the Kompli version, the Linux distribution and version,
  the procedure or benchmark involved, the exact command you ran, the relevant
  portion of the logs, and the expected versus actual behavior. A minimal
  reproduction (for example, the JSON/MOF payload or Lua snippet) makes triage much
  faster.
- **Feature request** — describe the use case, the benchmark or control it relates
  to, and why the existing functionality is insufficient.
- **Question / usage help** — for "how do I…" questions, start a thread in
  [GitHub Discussions](https://github.com/microsoft/kompli/discussions) when it is
  enabled; otherwise open an issue with the `question` label.

To help others find answers, please keep one topic per issue and use a clear,
specific title.

## Security issues

**Do not report security vulnerabilities through public GitHub issues, discussions,
or pull requests.** Follow the coordinated disclosure process described in
[SECURITY.md](SECURITY.md) instead.

## Contributing

If you would like to fix a bug or implement a feature yourself, see
[CONTRIBUTING.md](CONTRIBUTING.md) for development, testing, and pull-request
guidelines.

## Response expectations

Kompli is maintained by Microsoft. Issues and pull requests are reviewed on a
best-effort basis and the maintainers aim to respond to new, well-formed issues
within a few business days. There is no guaranteed service-level agreement for
this open-source project, and response times may vary around holidays and release
cycles.

## Microsoft Support Policy

Support for Kompli is limited to the resources listed above. For questions about
the Kompli project that are not suited to a public issue, you may contact the team
at [kompli@microsoft.com](mailto:kompli@microsoft.com).
